# GDAL7 Development Guide

Guidelines for generating cpp11 bindings and S7 classes from parsed SWIG interface definitions.

## Project Structure

```
GDAL7/
├── src/
│   ├── GDAL7_dataset.cpp      # cpp11 bindings for GDALDataset
│   ├── GDAL7_band.cpp         # cpp11 bindings for GDALRasterBand
│   ├── GDAL7_driver.cpp       # etc.
│   ├── GDAL7_group.cpp
│   ├── GDAL7_mdarray.cpp
│   └── cpp11.cpp              # Auto-generated by cpp11::cpp_register()
├── R/
│   ├── class-dataset.R        # S7 class definition
│   ├── class-band.R
│   ├── class-driver.R
│   ├── class-group.R
│   ├── class-mdarray.R
│   ├── generics.R             # All S7 generics in one place
│   └── zzz.R                  # .onLoad, library init
├── inst/
│   └── generator/
│       ├── parse_swig.R       # Parser (done)
│       ├── generate_cpp11.R   # cpp11 generator
│       └── generate_s7.R      # S7 generator
└── DESCRIPTION
```

## SWIG Parse Output Structure

The parser produces this structure for each class:

```r
class_def <- list(
  public_name = "Dataset",
  internal_name = "GDALDatasetShadow",
  parent = "GDALMajorObjectShadow",

  properties = list(
    list(name = "RasterXSize", type = "int", mutable = FALSE),
    list(name = "RasterYSize", type = "int", mutable = FALSE),
    list(name = "RasterCount", type = "int", mutable = FALSE)
  ),

  methods = list(
    list(
      name = "GetRasterBand",
      return_type = "GDALRasterBandShadow*",
      params = list(
        list(name = "nBand", type = "int", default = NULL,
             nonnull = FALSE, output = FALSE, typemap = NA)
      ),
      body = "return GDALGetRasterBand(self, nBand);",
      newobject = FALSE
    )
  )
)
```

## Type Mapping Reference

### Primitive Types

| SWIG/C Type | cpp11 Parameter | cpp11 Return | R Type |
|-------------|-----------------|--------------|--------|
| `int` | `int` | `int` | `integer` |
| `double` | `double` | `double` | `double` |
| `bool` | `bool` | `bool` | `logical` |
| `const char*` | `std::string` | `std::string` | `character` |
| `char*` | `std::string` | `std::string` | `character` |
| `void` | - | `void` (use `cpp11::nothing`) | `invisible(NULL)` |
| `GIntBig` | `int64_t` or `double` | `double` | `double` |
| `GByte` | `int` | `int` | `integer` (raw for arrays) |

### String List Types (from %apply typemaps)

| Typemap | C Type | Semantics | cpp11 Handling | R Type |
|---------|--------|-----------|----------------|--------|
| `char **CSL` | `char**` | NULL-terminated string list | `cpp11::strings` | `character` vector |
| `char **dict` | `char**` | KEY=VALUE pairs | `cpp11::list` with names | named `character` |
| `char **options` | `char**` | Creation options | `cpp11::strings` | `character` vector |

### GDAL Object Types

| SWIG Type | C Handle | cpp11 Storage | S7 Class |
|-----------|----------|---------------|----------|
| `GDALDatasetShadow*` | `GDALDatasetH` | `external_pointer<GDALDatasetH>` | `GDALDataset` |
| `GDALRasterBandShadow*` | `GDALRasterBandH` | `external_pointer<GDALRasterBandH>` | `GDALRasterBand` |
| `GDALDriverShadow*` | `GDALDriverH` | `external_pointer<GDALDriverH>` | `GDALDriver` |
| `OGRLayerShadow*` | `OGRLayerH` | `external_pointer<OGRLayerH>` | `OGRLayer` |
| `OSRSpatialReferenceShadow*` | `OGRSpatialReferenceH` | `external_pointer<OGRSpatialReferenceH>` | `SpatialReference` |
| `GDALGroupHS*` | `GDALGroupH` | `external_pointer<GDALGroupH>` | `GDALGroup` |
| `GDALMDArrayHS*` | `GDALMDArrayH` | `external_pointer<GDALMDArrayH>` | `GDALMDArray` |

### Output Parameters

When a parameter has `output = TRUE` (from `%apply (int *OUTPUT)`):

```cpp
// SWIG signature: void GetBlockSize(int *pnBlockXSize, int *pnBlockYSize)
// Generated cpp11:
[[cpp11::register]]
cpp11::list GDAL7_band_get_block_size(SEXP xp) {
    auto ptr = get_band_ptr(xp);
    int block_x, block_y;
    GDALGetBlockSize(*ptr, &block_x, &block_y);

    cpp11::writable::list result;
    result.push_back({"x"_nm = block_x});
    result.push_back({"y"_nm = block_y});
    return result;
}
```

## cpp11 Code Generation Patterns

### External Pointer Management

```cpp
#include <cpp11.hpp>
#include "gdal.h"

using namespace cpp11;

// Type alias for clarity
using dataset_ptr = external_pointer<GDALDatasetH>;

// Helper to extract and validate pointer
inline GDALDatasetH get_dataset_handle(SEXP xp) {
    dataset_ptr ptr(xp);
    if (!ptr) {
        stop("Invalid GDALDataset pointer (NULL or already closed)");
    }
    return *ptr;
}
```

### Method Patterns

**Simple getter (returns primitive):**
```cpp
[[cpp11::register]]
int GDAL7_dataset_get_raster_xsize(SEXP xp) {
    GDALDatasetH h = get_dataset_handle(xp);
    return GDALGetRasterXSize(h);
}
```

**Getter returning string:**
```cpp
[[cpp11::register]]
std::string GDAL7_dataset_get_projection(SEXP xp) {
    GDALDatasetH h = get_dataset_handle(xp);
    const char* proj = GDALGetProjectionRef(h);
    return proj ? std::string(proj) : std::string("");
}
```

**Method returning GDAL object (newobject = FALSE, borrowed reference):**
```cpp
[[cpp11::register]]
SEXP GDAL7_dataset_get_raster_band(SEXP xp, int band_num) {
    GDALDatasetH h = get_dataset_handle(xp);
    GDALRasterBandH band = GDALGetRasterBand(h, band_num);
    if (!band) {
        stop("Band %d not found", band_num);
    }
    // Borrowed reference - do NOT free
    // Store handle directly (not pointer to handle)
    return external_pointer<GDALRasterBandH>(new GDALRasterBandH(band));
}
```

**Method returning GDAL object (newobject = TRUE, caller owns):**
```cpp
[[cpp11::register]]
SEXP GDAL7_dataset_get_spatial_ref(SEXP xp) {
    GDALDatasetH h = get_dataset_handle(xp);
    OGRSpatialReferenceH srs = GDALGetSpatialRef(h);
    if (!srs) {
        return R_NilValue;
    }
    // Clone because we need to own it
    OGRSpatialReferenceH owned = OSRClone(srs);
    return external_pointer<OGRSpatialReferenceH>(
        new OGRSpatialReferenceH(owned),
        true,  // release prevent flag
        release_spatial_ref  // destructor function
    );
}

// Custom destructor
void release_spatial_ref(OGRSpatialReferenceH* p) {
    if (p && *p) {
        OSRDestroySpatialReference(*p);
    }
    delete p;
}
```

**Method with string list return (CSL):**
```cpp
[[cpp11::register]]
cpp11::strings GDAL7_dataset_get_file_list(SEXP xp) {
    GDALDatasetH h = get_dataset_handle(xp);
    char** files = GDALGetFileList(h);

    cpp11::writable::strings result;
    if (files) {
        for (int i = 0; files[i] != NULL; i++) {
            result.push_back(files[i]);
        }
        CSLDestroy(files);
    }
    return result;
}
```

**Method with options input:**
```cpp
[[cpp11::register]]
SEXP GDAL7_driver_create(SEXP driver_xp, std::string filename,
                          int xsize, int ysize, int bands,
                          int dtype, cpp11::strings options) {
    GDALDriverH drv = get_driver_handle(driver_xp);

    // Convert R strings to CSL
    char** opts = NULL;
    for (auto opt : options) {
        opts = CSLAddString(opts, std::string(opt).c_str());
    }

    GDALDatasetH ds = GDALCreate(drv, filename.c_str(),
                                  xsize, ysize, bands,
                                  static_cast<GDALDataType>(dtype), opts);
    CSLDestroy(opts);

    if (!ds) {
        stop("Failed to create dataset: %s", CPLGetLastErrorMsg());
    }

    return external_pointer<GDALDatasetH>(
        new GDALDatasetH(ds), true, release_dataset);
}
```

### Error Handling

```cpp
// Check CPLErr return values
[[cpp11::register]]
void GDAL7_dataset_set_projection(SEXP xp, std::string proj) {
    GDALDatasetH h = get_dataset_handle(xp);
    CPLErr err = GDALSetProjection(h, proj.c_str());
    if (err != CE_None) {
        stop("SetProjection failed: %s", CPLGetLastErrorMsg());
    }
}

// Check OGRErr return values
[[cpp11::register]]
void GDAL7_layer_start_transaction(SEXP xp) {
    OGRLayerH layer = get_layer_handle(xp);
    OGRErr err = OGR_L_StartTransaction(layer);
    if (err != OGRERR_NONE) {
        stop("StartTransaction failed with error code %d", err);
    }
}
```

## S7 Code Generation Patterns

### Class Definition

```r
#' @export
GDALDataset <- S7::new_class(
  "GDALDataset",
  package = "GDAL7",
  parent = GDALMajorObject,

  properties = list(
    # Internal pointer - not for user access
    .ptr = S7::class_any,

    # Read-only properties (from %immutable)
    raster_xsize = S7::new_property(
      class = S7::class_integer,
      getter = function(self) {
        .Call(GDAL7_dataset_get_raster_xsize, self@.ptr)
      }
    ),

    raster_ysize = S7::new_property(
      class = S7::class_integer,
      getter = function(self) {
        .Call(GDAL7_dataset_get_raster_ysize, self@.ptr)
      }
    ),

    raster_count = S7::new_property(
      class = S7::class_integer,
      getter = function(self) {
        .Call(GDAL7_dataset_get_raster_count, self@.ptr)
      }
    ),

    # Read-write property example
    projection = S7::new_property(
      class = S7::class_character,
      getter = function(self) {
        .Call(GDAL7_dataset_get_projection, self@.ptr)
      },
      setter = function(self, value) {
        .Call(GDAL7_dataset_set_projection, self@.ptr, value)
        self
      }
    )
  ),

  # Validator ensures pointer is valid
  validator = function(self) {
    if (is.null(self@.ptr)) {
      "Dataset pointer cannot be NULL"
    }
  }
)
```

### Generics and Methods

Define generics in `R/generics.R`:

```r
#' Get raster band from dataset
#' @param x A GDALDataset object
#' @param band Band number (1-indexed)
#' @return A GDALRasterBand object
#' @export
get_raster_band <- S7::new_generic("get_raster_band", "x")

#' Get file list for dataset
#' @param x A GDALDataset object
#' @return Character vector of file paths
#' @export
get_file_list <- S7::new_generic("get_file_list", "x")

#' Flush cache to disk
#' @param x A GDALDataset or GDALRasterBand object
#' @return Invisible NULL
#' @export
flush_cache <- S7::new_generic("flush_cache", "x")
```

Implement methods in class files:

```r
# In R/class-dataset.R

S7::method(get_raster_band, GDALDataset) <- function(x, band) {
  ptr <- .Call(GDAL7_dataset_get_raster_band, x@.ptr, as.integer(band))
  GDALRasterBand(.ptr = ptr)
}

S7::method(get_file_list, GDALDataset) <- function(x) {
  .Call(GDAL7_dataset_get_file_list, x@.ptr)
}

S7::method(flush_cache, GDALDataset) <- function(x) {
  .Call(GDAL7_dataset_flush_cache, x@.ptr)
  invisible(NULL)
}
```

### Constructor Functions

Users shouldn't call `GDALDataset(.ptr = ...)` directly. Provide friendly constructors:

```r
#' Open a GDAL dataset
#'
#' @param path File path or connection string
#' @param readonly Open in read-only mode (default TRUE)
#' @param options Character vector of open options
#' @return A GDALDataset object
#' @export
#' @examples
#' ds <- gdal_open("myfile.tif")
#' ds <- gdal_open("/vsicurl/https://example.com/cog.tif")
gdal_open <- function(path, readonly = TRUE, options = character()) {
  flags <- if (readonly) 0L else 1L  # GA_ReadOnly vs GA_Update
  ptr <- .Call(GDAL7_open_dataset, path, flags, options)
  GDALDataset(.ptr = ptr)
}

#' Create a new GDAL dataset
#'
#' @param driver Driver short name (e.g., "GTiff", "GPKG")
#' @param path Output file path
#' @param xsize Width in pixels
#' @param ysize Height in pixels
#' @param bands Number of bands
#' @param dtype Data type (default GDT_Byte)
#' @param options Creation options
#' @return A GDALDataset object
#' @export
gdal_create <- function(driver, path, xsize, ysize, bands = 1L,
                        dtype = GDT_Byte, options = character()) {
  drv_ptr <- .Call(GDAL7_get_driver_by_name, driver)
  ptr <- .Call(GDAL7_driver_create, drv_ptr, path,
               as.integer(xsize), as.integer(ysize),
               as.integer(bands), as.integer(dtype), options)
  GDALDataset(.ptr = ptr)
}
```

### Print Methods

```r
#' @export
S7::method(print, GDALDataset) <- function(x, ...) {
  cat("<GDALDataset>\n")
  cat("  Size:", x@raster_xsize, "x", x@raster_ysize, "\n")
  cat("  Bands:", x@raster_count, "\n")

  drv <- get_driver(x)
  if (!is.null(drv)) {
    cat("  Driver:", get_description(drv), "\n")
  }

  proj <- x@projection
  if (nzchar(proj)) {
    # Truncate long WKT
    if (nchar(proj) > 60) {
      proj <- paste0(substr(proj, 1, 57), "...")
    }
    cat("  Projection:", proj, "\n")
  }

  invisible(x)
}
```

## Naming Conventions

### Function Names

| SWIG Method | cpp11 Function | S7 Generic | Notes |
|-------------|----------------|------------|-------|
| `GetRasterXSize` | `GDAL7_dataset_get_raster_xsize` | (property) | Read-only property |
| `GetProjection` | `GDAL7_dataset_get_projection` | (property) | Property with getter/setter |
| `SetProjection` | `GDAL7_dataset_set_projection` | (property) | |
| `GetRasterBand` | `GDAL7_dataset_get_raster_band` | `get_raster_band` | Returns object |
| `FlushCache` | `GDAL7_dataset_flush_cache` | `flush_cache` | Void method |
| `BuildOverviews` | `GDAL7_dataset_build_overviews` | `build_overviews` | Complex method |

### R Style

- Use snake_case for all R functions and generics
- Properties are nouns: `raster_xsize`, `projection`, `block_size`
- Methods are verbs: `get_raster_band`, `flush_cache`, `build_overviews`
- Constructors: `gdal_open`, `gdal_create` (not `open_dataset`)

## Memory Management Rules

### Ownership

1. **Dataset**: User owns. Close explicitly or via garbage collection.
2. **Band from Dataset**: Borrowed reference. Do NOT free. Invalidated when dataset closes.
3. **Driver**: Singleton. Never free.
4. **SpatialReference from GetSpatialRef**: Borrowed. Clone if you need to keep it.
5. **SpatialReference from CreateXXX**: Caller owns. Must free.
6. **String from GetXXX**: Usually static/borrowed. Copy immediately.
7. **String list (char**)**: If you called a Get function, usually borrowed. If Create/Set, you own input.

### Prevent Use-After-Free

```r
# In GDALRasterBand, store reference to parent dataset
GDALRasterBand <- S7::new_class(
  "GDALRasterBand",
  properties = list(
    .ptr = S7::class_any,
    .parent_dataset = S7::class_any  # Prevents GC of dataset while band exists
  )
)

# When creating band from dataset:
S7::method(get_raster_band, GDALDataset) <- function(x, band) {
  ptr <- .Call(GDAL7_dataset_get_raster_band, x@.ptr, as.integer(band))
  GDALRasterBand(.ptr = ptr, .parent_dataset = x)
}
```

## Testing Strategy

### Unit Tests

```r
test_that("dataset properties work", {
  ds <- gdal_open(system.file("extdata/test.tif", package = "GDAL7"))

  expect_s7_class(ds, GDALDataset)

  expect_equal(ds@raster_xsize, 100L)
  expect_equal(ds@raster_ysize, 100L)

  band <- get_raster_band(ds, 1)
  expect_s7_class(band, GDALRasterBand)

  gc()
  expect_equal(band@band_number, 1L)  # Should still work
})
```

## Generator Implementation Notes

### Template Approach

Use glue or whisker for code generation:

```r
generate_cpp11_getter <- function(class_name, method) {
  template <- '
[[cpp11::register]]
{return_type} GDAL7_{class_lower}_{method_lower}(SEXP xp) {{
    {handle_type} h = get_{class_lower}_handle(xp);
    return {call};
}}'

  glue::glue(template,
    return_type = map_return_type(method$return_type),
    class_lower = tolower(class_name),
    method_lower = to_snake_case(method$name),
    handle_type = get_handle_type(class_name),
    call = generate_call(method)
  )
}
```

### Handling Edge Cases

1. **Overloaded methods**: SWIG shows multiple signatures. Generate separate R functions or use `...` dispatch.

2. **Callbacks**: GDALProgressFunc needs special handling. Create a C++ wrapper that invokes R function.

3. **Arrays**: `double argin[6]` for geotransform. Use `cpp11::doubles` and validate length.

4. **Optional output params**: Pattern `void GetXXX(double* val, int* has_val)`. Return list or use R's NA.

5. **Enums**: Generate constants in R, use integer conversion in cpp11.

## File Generation Order

1. `R/zzz.R` - Library initialization, GDAL setup
2. `R/constants.R` - All enum values (GDT_*, GA_*, etc.)
3. `R/class-major-object.R` - Base class
4. `R/class-driver.R` - No dependencies
5. `R/class-spatial-ref.R` - Standalone
6. `R/class-dataset.R` - Depends on driver, spatial-ref
7. `R/class-band.R` - Depends on dataset
8. `R/class-layer.R`, etc. - OGR classes
9. `R/class-group.R`, `R/class-mdarray.R` - Multidimensional
10. `R/generics.R` - All generic definitions
11. `src/*.cpp` - Generated in parallel with R classes
