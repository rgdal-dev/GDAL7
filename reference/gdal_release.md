# The GDAL library GDAL7 is running against

The GDAL library GDAL7 is running against

## Usage

``` r
gdal_release()
```

## Value

A named character vector: the `release` name, its `date`, and the full
`version` string GDAL reports.

## Examples

``` r
gdal_release()
#>                                           release 
#>                                          "3.12.2" 
#>                                              date 
#>                                        "20260203" 
#>                                           version 
#> "GDAL 3.12.2 \"Chicoutimi\", released 2026/02/03" 
```
